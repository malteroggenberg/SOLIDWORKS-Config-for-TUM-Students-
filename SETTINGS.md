# SOLIDWORKS Settings (System & UI)

This file documents all changes included in the SOLIDWORKS settings export (`.sldreg`).

These settings affect:

- system behavior
- user interface
- workflow
- visual appearance

⚠️ Important:
Drawing-specific settings (dimensions, fonts, etc.) are NOT included here.  
They are stored in the templates.

---

##  Goal of these settings

The configuration is designed to:

- reduce unnecessary clicks  
- improve visibility and clarity  
- speed up access to important tools  
- create a consistent working environment  

---

##  Display

- edges are smoothed for cleaner visuals  
- no aggressive performance settings changed  

→ goal: better visual quality without performance loss

---

##  Colors

- drawing-related colors were unified  
  (e.g. removing distracting default colors like purple)

- front plane is slightly highlighted  

→ goal:
- better orientation in sketches  
- cleaner visual appearance  

---

## 📁 File Locations

- document templates are preconfigured  
- sheet formats are linked  
- only relevant folders are used  

→ goal:
- no searching for templates  
- faster file creation  

---

##  Default Templates

Default templates are assigned for:

- Part  
- Assembly  
- Drawing  

→ new files automatically start with the correct setup

---

##  Workflow / UI Optimization

The UI is optimized for fast access to frequently used tools.

### Key changes:

- filter is visible and easily accessible  
- equations tool is directly reachable  
- measurement tool placed for quick access  
- reference geometry tools easier to access  
- "repair sketch" is visible  
- sketch relations (show/add) easier to access  
- relevant tabs activated:
  - sheet metal  
  - weldments  

→ goal:
- reduce menu navigation  
- faster modeling workflow  

---

##  Included Settings

The `.sldreg` file contains:

- system options  
- CommandManager configuration  
- toolbars  
- keyboard shortcuts  
- mouse gestures  
- menu customizations  

→ this is a full workflow setup, not just visual tweaks

---

## ⚠️ Important Note on Templates

These settings do NOT include:

- dimension styles  
- fonts  
- line thickness  
- drawing standards  

These are stored in the templates.

This means:
- importing the settings alone is not enough  
- templates must be installed and linked  

---

##  After Import

Check:

- are colors applied correctly?  
- are tabs visible?  
- are tools easily accessible?  
- are templates available?  

If yes → setup is complete.

---

##  Troubleshooting

If something is not working:

1. check file paths  
2. check template folders  
3. restart SOLIDWORKS  

---

## Summary

This configuration combines:

- cleaner visuals  
- faster access to tools  
- structured workflow  
- consistent setup  

→ less friction, faster work in SOLIDWORKS
